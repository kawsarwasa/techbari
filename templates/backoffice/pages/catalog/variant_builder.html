How it works

Global, not per-product.
Color, Storage, Region, RAM, Size and every custom attribute live once in the library. A product only receives generated SKU combinations that reference those reusable values.
No duplicate business database.
Purchase, POS, Inventory, Serial/IMEI, Returns and Accounting continue to reference the same stable ProductVariant IDs. The builder changes only how those SKUs are configured.
Preset example.
Smartphone → Color + Storage + Region. Laptop → Color + RAM + Storage. Presets never create extra stock or pricing records.
